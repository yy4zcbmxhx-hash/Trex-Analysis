# Trex verified evidence

Values in trex_verified_facts.json are transcribed from official SEC tables. Monetary values are USD thousands, not millions; shares are actual share counts.

- 2025 10-K, F-4 income, F-5 balance, F-7 cash flow, F-8–F-10 inventory restatement: https://www.sec.gov/Archives/edgar/data/1069878/000119312526068732/trex-20251231.htm
- 2026 Q2 earnings release, August 4 2026, pages6–10: https://www.sec.gov/Archives/edgar/data/1069878/000119312526331450/trex-ex99_1.htm
- 2026 Q2 10-Q: https://www.sec.gov/Archives/edgar/data/1069878/000119312526332813/trex-20260630.htm

2023–24 comparative figures reflect retrospective LIFO-to-FIFO adjustment; do not mix them with original-year balance/earnings. June30 balance figures are not October26 marks. Management guidance is not a forecast guarantee. Raw HTML download was blocked by SEC; numerical extraction used web-readable official SEC pages.
